# 🚀 AI Career Mentor

AI Career Mentor is an intelligent career guidance platform built using Python and Streamlit. It helps students and job seekers analyze resumes, calculate ATS scores, identify skill gaps, explore career roadmaps, prepare for interviews, and receive personalized career guidance.

## ✨ Features

* 📄 Resume Parsing and Skill Extraction
* 📊 ATS Score Calculation
* 🎯 Job Role Prediction
* 📈 Skill Gap Analysis
* 💡 Resume Improvement Suggestions
* 📚 Course Recommendations
* 🎤 Interview Question Preparation
* 🗺 Personalized Career Roadmaps
* 🤖 AI Career Chatbot
* 📝 Career Report Generation (PDF)
* 🔐 User Authentication System
* 💾 Chat History Storage using SQLite

## 🛠 Technologies Used

* Python
* Streamlit
* Scikit-Learn
* SQLite
* Pandas
* NumPy
* Matplotlib
* PyPDF2
* ReportLab

## 🚀 How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
